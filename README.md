# 👕 VesteArte — Streetwear Autoral

![VesteArte Banner](https://img.shields.io/badge/Status-Em%20Desenvolvimento-orange?style=for-the-badge)
![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)

A **VesteArte** é uma plataforma de e-commerce de streetwear focada em estampas autorais que conectam cultura urbana, música, games e raízes regionais. O projeto une um design minimalista e moderno com uma experiência de compra ágil, finalizada diretamente via WhatsApp.

---

## 🎨 Design & Conceito

O projeto foi construído sob uma estética "Neo-Brutalista" suave, utilizando:
- **Tipografia:** `Bebas Neue` para títulos de impacto e `DM Sans` para leitura técnica.
- **Sistema de Cores:** Tokens dinâmicos que alteram a identidade visual conforme a categoria (ex: Verde para Futebol, Roxo para Games).
- **Dark Mode:** Suporte nativo para conforto visual em qualquer ambiente.

---

## 🚀 Funcionalidades

- [x] **Catálogo Dinâmico:** Filtragem por categorias (Futebol, Games, Filmes, Anime, Música e Cultural).
- [x] **Busca em Tempo Real:** Filtro inteligente por nome ou descrição do produto.
- [x] **Carrinho de Compras:** Drawer lateral interativo com persistência de dados em sessão.
- [x] **Ordenação Inteligente:** Filtros por preço (maior/menor) e novidades.
- [x] **Checkout WhatsApp:** Integração direta que gera uma lista de pedido formatada para o vendedor.
- [x] **UI/UX Responsiva:** Totalmente adaptado para dispositivos móveis.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando tecnologias web fundamentais para garantir performance e facilidade de manutenção:

*   **HTML5:** Estruturação semântica.
*   **CSS3:** Variáveis (Tokens), Grid Layout, Flexbox e animações customizadas.
*   **JavaScript (ES6+):** Manipulação de DOM, lógica de carrinho e filtros dinâmicos.
*   **Google Fonts:** Integração de fontes personalizadas.
